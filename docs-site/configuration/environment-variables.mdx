title: "Environment Variables"
description: "Complete settings reference: every env var, its type, default, and what it controls."
---

All configuration lives in `Settings` (`src/app/config/settings.py`), a frozen Pydantic Settings model loaded from `.env.development` or the process environment. Names are **case-sensitive**. Secret-valued fields are `SecretStr` — automatically redacted in logs, reprs, and dumps.

<Note>
Production guardrail: when `ENVIRONMENT=production`, startup fails if any secret field still holds its documented default (`JWT_SECRET_KEY`, `NEO4J_PASSWORD`, `GEMINI_API_KEY`, `POSTGRES_PASSWORD`, `RABBITMQ_DEFAULT_PASS`, OAuth/S3/Tavily/Pinecone keys). Outside production the same condition logs a warning.
</Note>

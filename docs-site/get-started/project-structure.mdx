## The feature module convention

Everything user-facing lives in `src/app/features/<name>/` with the same internal shape:

| File | Responsibility |
| --- | --- |
| `router.py` | Thin HTTP layer: routing, status codes, response envelope |
| `dto.py` | Pydantic request/response models |
| `dependencies.py` | DI wiring: repositories → services → guards |
| `service.py` | Business logic, structured logging, error mapping |
| `repository.py` | Persistence only — no HTTP concerns |
| `model.py` / `constants.py` | Domain models and shared constants |

Adding a feature means adding a directory with this shape and registering its router in `src/app/api/` — nothing else.

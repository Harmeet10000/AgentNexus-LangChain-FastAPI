# Coverage Matrix — legal_retrieval_v2

The documented target for this golden set is **150–300 labeled queries**. This
matrix is the contract that the count must be measured against: a query added
only to inflate the count without extending coverage is rejected in review.
The auto-maintained row-map section at the bottom is generated by
`scripts/check_golden_coverage.py` (run in CI), which verifies that every row
maps to a declared matrix cell and that the composition minimums below hold.

Growth history: the Wave 2B-2 authoring run landed 105 rows; the wave-4 growth
run (2026-11-02, `retrieval-measurement-gate`) appended 50 machine-verified
rows mined from the corpus artifacts, reaching **155**.

## Dimensions

- **Document family** (`document_kind`): `contracts`, `statutes`, `judgments`,
  `filings`.
- **Jurisdiction**: `India` (IN sources: NHAI, Railway Board, SCI, synthetic
  Indian-law fixtures) and `GB` (CCS/UK decoys SRC-14/15/16).
- **Difficulty**: `easy`, `medium`, `hard` (manifest-declared bands).
- **Query style** (documented coarse classification of the query text, applied
  by `scripts/check_golden_coverage.py`):
  - `obligation_lookup` — who must do what, what rate/amount/term applies;
  - `cross_reference` — answers that require following an internal reference
    (clause/article/schedule/annexure pointers, packet membership, editions)
    or synthesizing across documents;
  - `permission` — "does X allow Y" questions (an allowance, an excuse, a
    prohibition, or their denial);
  - `temporal` — dates, periods, cure windows, limitation periods.
- **Profiles** (overlay, not a per-row dimension):
  - **multi-contract** — documents with recorded contract boundaries
    (`evals/corpus/README.md` §4): SRC-04 (5 boundaries, the 5-boundary packet
    among them), SRC-14 (2 boundaries incl. the embedded template), SYN-02
    (2 twin contracts in one file). Exercised by `multi_contract_boundary`
    rows and by twin-discrimination rows.
  - **scanned-OCR** — SRC-05 and SRC-06 are image-only scans with zero text
    layer (referenced by `heavy_noise` abstention-family rows only — the
    chunking convention gives them zero chunks, so they cannot anchor
    answerable rows); SRC-07 (scanned circular prefix, noisy text layer) and
    SYN-05 (scanned-style re-render with embedded text layer) anchor
    `light_noise` answerable rows.

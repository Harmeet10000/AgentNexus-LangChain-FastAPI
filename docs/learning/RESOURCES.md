# Resources

High-trust sources grounding this course. Every lesson cites these.

## Primary sources

| # | Resource | Role | Link |
|---|----------|------|------|
| R1 | *Unit Testing: Principles, Practices, and Patterns* — Vladimir Khorikov (Manning, 2020) | The definitive modern book on unit-test philosophy: what to test, what to skip, test doubles, anti-patterns. **Primary book of the course.** | https://www.manning.com/books/unit-testing |
| R2 | *The Practical Test Pyramid* — Ham Vocke (martinfowler.com) | Canonical map of where each kind of test lives and why the pyramid shape matters. | https://martinfowler.com/articles/practical-test-pyramid.html |
| R3 | *Write tests. Not too many. Mostly integration.* — Kent C. Dodds | The counterpoint to pure unit-testing culture; origin of the Testing Trophy model. | https://kentcdodds.com/blog/write-tests |
| R4 | *Software Engineering at Google* — ch. 11–14 (free online) | How Google thinks about test sizes, flaky tests, and testing beyond the developer loop. | https://abseil.io/resources/swe-book/html/ch11.html |
| R5 | *Test Sizes* — Google Testing Blog | Small/Medium/Large classification — senior-level vocabulary for test scope. | https://testing.googleblog.com/2010/12/test-sizes.html |
| R6 | *Site Reliability Engineering* — Google (free online) | Error budgets, monitoring philosophy, canary analysis — production-side testing. | https://sre.google/books/ |

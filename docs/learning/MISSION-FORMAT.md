# MISSION.md Format

```markdown
# Mission

**One bold sentence: what mastering this topic makes possible.**

## Goals (in priority order)
1. **<Goal name>.** <Why it matters, concretely.>
...

## Constraints & preferences
- Level: <current ability>
- Stack/medium: <what examples should use>
- Pace: <session shape>
- Method: <how learning should happen>

## Definition of success
<Observable capability the learner will have — phrased as things they can DO.>
```

Rules:
- Ground every lesson in a goal; if a lesson serves no goal, don't teach it.
- Missions change as learners grow — confirm with the learner before rewriting, then log a learning record.

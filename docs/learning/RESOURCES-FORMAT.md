# RESOURCES.md Format

Two tables: **Primary sources** (R-prefixed) and **Supporting** (S-prefixed), plus **Communities**.

| # | Resource | Role | Link |
|---|----------|------|------|

Rules:
- Only add resources verified to exist (fetched or search-confirmed) — never trust parametric memory for URLs.
- `Role` states what this resource grounds in the curriculum (e.g., "primary book for unit-test philosophy").
- Lessons must cite resource IDs (R1–R5, S1–S3).

# Learning Record Format

Filename: `NNNN-dash-case-name.md`, incrementing NNNN.

```markdown
# 0001: <Title>

**Date:** YYYY-MM-DD · **Status:** current | superseded by NNNN

## Context
What prompted capturing this — session events, questions asked, work produced.

## Insight / Decision
The non-obvious lesson or curriculum decision itself.

## Implications
How this drives future sessions: what to revisit, what to interleave, what to revise.
```

Use records for: baseline snapshots, mission changes, revised understanding of the learner's ZPD, insights that contradict earlier assumptions.
